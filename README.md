# RM STORE NEW

## تشغيل المشروع على Windows

افتح مجلد المشروع في VS Code، ثم من Terminal نفّذ:

```powershell
npm install
npm run dev
```

افتح الرابط المحلي الذي يظهر في التيرمنال (غالباً http://localhost:5173).

## المرحلة الحالية
- قائمة قطع الكمبيوتر مع زر + لعرض التصنيفات الفرعية الثمانية.
- تصفية منتجات قطع الكمبيوتر حسب التصنيف الفرعي.
- أداة أولية لتجميع جهاز من نفس بيانات قطع الكمبيوتر مع حساب المجموع تلقائياً.

ملاحظة: بيانات المنتجات والأسعار تجريبية، ولم يتم بعد ربطها بقاعدة Supabase أو المخزون الفعلي.
